# public noise — Website Mockup

Vorzeigbares Konzept-Mockup für **public noise Veranstaltungstechnik**.

## Lokal öffnen

```bash
python3 -m http.server 4173
```

Dann `http://localhost:4173` im Browser öffnen.

## GitHub Pages

Repository auf GitHub anlegen, den Inhalt dieses Ordners pushen und unter **Settings → Pages** den Branch `main` / Root als Quelle wählen.

## Hinweis

Dies ist ein Website-Konzept. Öffentliche Fakten wurden auf Name, Branche, Adresse und E-Mail-Adresse begrenzt. Nicht verifizierte Referenzen, Logos, Telefonnummern und Social-Profile wurden bewusst nicht ergänzt.
